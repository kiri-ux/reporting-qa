SEO PLUS LIVE CHAT IS TWO REPORTS
=================================
Alegre Construction 53167: SEO live, Live Chat live, nothing else.

Live Chat never brings a report with it - it appears on the report of whatever
it was sold alongside. When that something is SEO, the SEO report is a separate
file pulled outside TapClicks, so there was nowhere for the Live Chat to go. It
attached to nothing, no monthly row existed, and the board could only say
"worth a closer look".

The client IS running another product, which is the test Live Chat has always
had. So Alegre now has two rows: an SEO row carrying SEO, and a monthly row
carrying Live Chat. Two files, as you said.

Two things that did not change, both tested: Live Chat on its own is still no
report at all, and Live Chat does not land on the SEO row - SEO is pulled
outside TapClicks and Live Chat is not on it.


THE ORDER'S STATUS IS ON THE LIST CHECK
=======================================
New column, "Order says", between the order id and the reason. "Nothing served
this month" beside "IO Paused" is a decision you can make on that page; either
one on its own is a question that used to mean opening the IO tool.

It needed one thing behind it. The statuses worth reading there are exactly the
ones that got a row DROPPED at import - paused, complete, ended - and by then
there is no order line left to read a status off. So the import now writes down
what the export said every order was, whether or not its rows survived, and the
column reads from that. All American Glass 51808 shows "IO Paused" beside "the
export has this order and every line on it ended 2026-07-21".
