A CANCELLED CAMPAIGN IS NEVER TOLD IT RUNS TO A DATE
====================================================
The Ooten Law Firm, 47028, cancelled top to bottom, was told

  the campaign runs to 2026-12-31, past this cycle's lifetime window

That date is what the campaign was SOLD to run to. Nothing on the export says
the day somebody hit cancel, so the date stopped meaning anything the moment
the order was cancelled - and quoting it says the campaign is still running.

A cancelled or completed order gets its own answer now, and which one depends
on what is actually known:

  order 47028 is cancelled. The date on it is what it was sold to run to, not
  the day it stopped, so nothing here says which cycle the lifetime belongs to.
  Approve it if it is this one.

With a serving file loaded and no delivery this month it says that instead, and
if another order for the client is still running it names it.

"Every line on this order is canceled" is also gone from lifetime rows. That is
a monthly's answer - a cancelled campaign is not owed a monthly, and it is
exactly what a lifetime IS for.
