CREDIT UNION AUDIT GROUP - and "how can I check if it's in our lists"
=======================================================================
There is a box for that now, on the Order list page:

  Is this order in the lists?    [ 54568 ]  [ Look it up ]

Type an order id, a client, or a partner. It answers the three questions a
missing order actually raises, in the order you would work through them:

  1. Is it loaded at all - and if it is, every line, with its partner, product,
     status and dates.
  2. Is it loaded under a DIFFERENT partner than the one delivering it, which
     is the Shasta case and reads as missing.
  3. Did that partner's export land at all - it says which, because "the file
     never arrived" and "the file arrived without this client in it" are
     different afternoons.

It also prints when the order list was last read, since an order created after
that is not in it however live it looks in the IO tool. Order 54568 was
submitted in June and the panel says Growth by Design has no orders loaded at
ALL, so that one is a file that did not land rather than anything about the
order.

Reports already on the board for that client are linked from the same panel.
