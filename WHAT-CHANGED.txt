EACH ORDER IS ITS OWN PILL
=============================
Kerr-Bilt Trailers read "50360 53901" in one grey block with a blue dot and a
green dot beside it: two orders, two statuses, and nothing tying either to
either.

Each order id is its own pill now, coloured by what THAT order says. Green
live, orange paused, red cancelled, blue complete, and the words on hover.

Which needed a fact the board did not have. The status list was every status
across the whole row, so it could not say which order carried which. It is
read off the line items themselves now - the per-line detail from build 88 -
as one status per order id.

An order with a live line item and a cancelled one is a LIVE order, so the
status that means "still delivering" wins. A red pill on an order still
running is the kind of wrong that gets a report pulled to the wrong end date.


PACING WAS MISSING THE PERFORMANCE MAX SPEND
===============================================
Kerr-Bilt's Performance Max carries $20,000 for the whole campaign and nothing
per month, so the spend row read "-/- no comparison" while the impressions
rows above it were being paced against real monthly goals. Two units on one
panel, and the one the client is actually billed on was the blank.

The lifetime panel already does this in reverse - a monthly goal multiplied
out across the flight, labelled as derived. Same thing the other way up now:
the campaign total divided by the months it covers, and the row says "the
campaign total over 8 months" rather than presenting it as something the order
stated.

A real monthly figure is never replaced by a derived one. This only fills a
blank.
