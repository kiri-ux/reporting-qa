NO PREVIEW LINK ON A CREATIVE
================================
New check. The Social Mirror AI grid prints "Click to View" with the ad's URL
behind it, one per variant, and a row with that column empty is a variant
nobody reading the report can see - which is the column somebody opens when
they want to know what an underperforming variant actually looks like.

"3 of 11 creatives have no preview link", on the widget it happened in.


A ROW AT 0% WATCHED
======================
New check, and the other half of the one that shipped in build 93. That one
fails when EVERY row of a completion column is zero, which is a broken widget.
This one warns when SOME are: one creative at 0.00% among nine that watched
fine is not a metric fault, but it is not something to send a client without
having looked at it either.

Only on the widgets where a completion rate is the point of the buy - video,
CTV, audio. A percentage column on a display grid is something else.


WHITEFIELD MEDIA, AND THE 23 MARCH 2020 PULL
===============================================
Nothing on the export says when somebody hit cancel. So a campaign called off
in 2021 can still be dated to 2027, and the pull list's test - "does this order
end after the cutoff" - kept it forever. Whitefield Media has no live order at
all and was asking for a pull reaching back six years on the strength of one.

A row nobody is running any more is now judged on the LINE ITEM's own end,
which is the last date anything was actually bought to deliver. A live row is
still judged on the order's end, because an open-ended one genuinely has no
end yet. A cancelled campaign that stopped last month still gets its full
range, because its lifetime covers the whole thing.

AND THE WHOLE LIST CAN BE AUDITED. "Whitefield Media, 23 March 2020" is a claim
about an order somebody has to be able to find, so there is a second download
on the orders page: every partner's date with the line items behind it, each
one marked counted or not and why. That answers "are there any others" without
either of us guessing.
