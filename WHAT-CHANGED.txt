1. Order 55216, and why the fix did not stick
-----------------------------------------------
Same disease as the DOOH one, and I only cured half of it.

The order export is parsed once and only the result is kept, so I made the S3
sync re-read the file whenever the PRODUCT MAPPING changed. But the rule that
rescues order 55216 - a live line item overruling a header that says "IO
Pending Launch" - lives in orders_io.py, not in the mapping. That file was not
part of the fingerprint, so the fix shipped and the loaded orders kept the old
answer, exactly as before.

The fingerprint now covers every file whose output is baked into an order
line: the product mapping, orders_io.py, and roster.py. On the first deploy
after this the export is re-read on its own, and reports for any client whose
product set moved are queued for a re-check.

54976 should come right in the same pass, for the same reason - it is the same
shape of order. To check whether it is loaded at all, the Orders page search
matches the whole row, so typing 54976 in it will find the order and line ids.


2. Re-check on a partner skips reports already signed off
-----------------------------------------------------------
"6 of 8" on a partner with one report pending, grinding through six that
somebody had already read and signed. The button means "bring this partner up
to date", and a signed-off report is up to date by definition.

The count on the button follows the same rule, so it no longer says 8 when
there are 2 to do.

The BACKGROUND SWEEP still covers signed-off reports - that is how a rule
change reaches one and pulls the sign-off if it finds a failure that was not
there when they signed. This only narrows the button. A single signed-off
report can still be re-read with "Check this file again" on its own page.


3. The 5% site rule needs volume behind it
--------------------------------------------
"Slicing Hero: Sword Master: 10 clicks on 183 impressions is 5.46%". One click
either way moves that half a point, and 183 impressions of a 62,679-impression
campaign is not something anybody is going to act on.

5% now applies from 1,000 impressions up. Below that the row is judged against
15% instead of being dropped - because the case this check was written for was
"Slicing Hero: Sword Master", 365 clicks on 783 impressions, 46.62%, and a
flat impressions floor would have thrown it away. No volume makes 46% a
coincidence.
