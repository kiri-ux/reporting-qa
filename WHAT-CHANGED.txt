UNDOING A REVIEWED
==================
There was no way to take a verdict off. The buttons were Reviewed, Needs fix
and Waive, so undoing a Reviewed meant pressing Needs fix - which is not
"never mind", it is "this report is wrong", and it holds the report out of the
partner's folder.

Clear verdict does what you asked for: the row goes back to unlooked-at. No
state, no name, no timestamp. It is not marked wrong and nothing is held back.

Three places:

  - the report page, beside Reviewed / Needs fix / Waive
  - each cycle row, as the same undo arrow the row overrides use, showing only
    on a row that already carries a verdict
  - the bulk bar at the top of the cycle list, for a batch of them

Clearing does not need a name typed in. Every other state records who said so;
this one is the absence of anybody having said anything, and leaving a name on
a row with no verdict reads as signed by somebody.

One thing it deliberately does NOT do: it will not produce the "Jacob signed
this off, then a re-check found a failure" line. That message is for a
sign-off the system pulled on its own, which is a different event, and it
turns up on exactly the same fields.
