1. CANCELLED GETS A LIFETIME. IT DOES NOT GET A MONTHLY.
--------------------------------------------------------
Build 83 took cancelled lines off the board completely, which was too far. You
said it plainly: a cancelled order still ran, and if it never got a lifetime it
still needs one to close out the campaign. What it does not need is another
month's report for the month somebody stopped it.

So the board now keeps cancelled lines, and a cancelled line is:

  not live      -> no monthly
  finished      -> owed a lifetime, unless one has already gone out

The expected-products list for a lifetime also has cancelled products back in
it. A cancelled buy is still on the lifetime, because cancelling does not mean
it never ran.


2. ALL LINES "IO COMPLETE" MEANS THE CAMPAIGN IS OVER
-----------------------------------------------------
Order 45911, Sorge Funeral Home. Every line reads IO Complete and the end dates
run to December, so nothing had "ended" by the calendar and no lifetime was
asked for.

IO Complete is the seller saying it is finished - the same statement the end
date makes, only earlier and more reliably. The importer now records it per
line item, folds it across the lines behind each row, and the board treats a
row where every line is complete exactly like one that has ended.


3. LIVE CHAT DOES NOT HOLD UP A LIFETIME
-----------------------------------------
River Valley Builders. Their Mobile Conquesting ended in July, and the lifetime
never appeared because two other orders were still open - 31171 and 43182, both
Live Chat only.

Live Chat gets no report of its own, so an order carrying only Live Chat is not
a campaign anybody is waiting on. It no longer blocks the lifetime of the
campaign that actually finished. An order carrying Live Chat AND something else
still blocks, and so does any real running order - that rule is unchanged and
tested both ways.


4. COMPLETION RATES ARE ASKED PER PRODUCT
------------------------------------------
Congressman Mike Kelly, July. Page one carries a CTV Completion Rate tile. Page
four carries an Online Audio table with Impressions, Clicks and CTR and no
completion rate at all - and the report passed.

The check was asking whether the word "Completion" appeared anywhere on the
report. It did, once, about CTV, and that answered for everything.

On reports with no section banners it now asks per product: does this product's
name and the word "completion" share a line. TapClicks names these widgets
after the product - "CTV Completion Rate", "Online Audio Completion
Performance" - so that is the shape it looks for. Renaming the widget properly
clears the finding.
