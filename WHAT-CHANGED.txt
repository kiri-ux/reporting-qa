"XX checks" - WHAT THAT IS
=============================
That was my wording in the guide, and it was not clear. It is the amber button
in the board toolbar, beside the "orders" button, and it carries a count - so
on screen it says something like "40 checks". It means those reports were
judged by older checking code. A background sweeper is already working through
them; the button does them now. It skips anything signed off.

The guide says that properly now, in both places it came up.


TWO MORE SECTIONS IN THE GUIDE
=================================
Lifetimes delivered - has this campaign already had its closeout? Every
lifetime that has gone out, with the cycle it went in. If it is on that page it
went; if the board is asking again anyway, the order's end date moved after it
was sent, so it really is owed again for the new ending.

Batch history - did the report ever arrive? Every batch the tool has taken in.
If the batch is not there, it never reached the tool, and no amount of waiting
on the board will fix that. If the batch is there and the report is not on the
board, it arrived under a name that did not join to anything.

Both are also in the troubleshooting table and the nav list at the top.
