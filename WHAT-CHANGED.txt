ONE ROW PER ORDER AND LINE ITEM
==================================
Long Jewelers - VB Blvd was one row reading

  ORDER 48135, 53342 | LINE ITEMS 127806, 127821
  FLIGHTS 2026-04-01 -> 2026-12-31   2026-05-01 -> 2026-12-31

which is three lists side by side with nothing tying them together. Two of
those dates belong to an order that is not on the other line.

Everywhere else in the app an order line is one answer per client and product,
merged across every order that sells it, because that is the question the
checks ask. This panel is the one place a person is asking the other question,
so it now keeps the line items themselves as well as the answer and prints one
row each - its own order, its own line item, its own dates, its own status, its
own "did it run this month".

The rows are still merged everywhere else. Nothing about the board changed.

48135 IS OFF THE JULY REPORT
===============================
This one was not a display problem.

Order 48135 is IO Complete and ended 28 February. Its Social Mirror line item
127806 is still dated 1 April to 31 December. The import took the line item's
end date whenever it had one, so 48135 read as running until December and went
on Long Jewelers' JULY order list as a live buy - five months after somebody
closed the order.

A line item cannot deliver past the order that pays for it. When the order is
CLOSED - complete or cancelled - its end date now wins. Only then: a live order
with a stale header date is the opposite case, the line item is the newer fact
there, so this is not a plain earliest-of-the-two.

That fix is in the import, not the panel, so it also takes 48135 off the board.

One more, related: the orders are read for the month being worked on, so a July
report gets looked at against an August import, and a buy that does not start
until August was on its order list looking like evidence. Those move below the
fold now - "N more line items that did not run in 2026-07", one click to open.
They are the same client and often the same product, so they are worth being
able to see; they are just not what the report is judged against.
