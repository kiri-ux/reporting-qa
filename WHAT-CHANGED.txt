THE LOGO PANEL
=================
Your wording, both states.

  Logo being used on the report. Flagging as a different status will force all
  other reports using this logo to be re-checked.

  [ Flag as default logo ]        [ Flag as real logo ]

The old line - "if this is the reporting tool's default rather than a station
or client logo, say so once and every report carrying it will fail" - was an
instruction addressed at whoever happened to be reading, and it described the
consequence as though it were the thing itself. The consequence worth naming is
the one that reaches other people's reports, which is now the second sentence.

When a logo is already flagged as the default, the panel still says so before
that sentence, because that is a fact about the logo rather than about the
button.
