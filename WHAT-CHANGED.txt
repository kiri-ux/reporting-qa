1. WHY THERE ARE STILL EXTRA REPORTS - AND IT IS THE SAME BUG AS LAST TIME
---------------------------------------------------------------------------
"Cancelled" and "IO Complete" say a campaign is OVER. Neither says WHICH MONTH
it ended in, and its end date on the export still reads whatever it was sold to
run to. So closing out on the flag alone closes out every campaign that has
ever finished, all into this one cycle.

Build 90 narrowed it to "every line on the client has stopped", which took out
26 rows and left the rest, because the rest are real finished campaigns - just
finished in March, or last November.

The serving file dates them. A campaign that delivered this month is one that
finished this month. One that last delivered in March finished in March and is
not this cycle's work. So a cancelled or complete campaign now only earns a
lifetime if the serving file shows it delivering in the data month.

With no serving file loaded for a month, nothing changes - the flag stands on
its own, as before.


2. OVERRIDES, BOTH WAYS, WITH A NOTE
-------------------------------------
On a row with no PDF:

  [note] [Done, no report] [Not needed]

On the "not owed this cycle" list, every row now has:

  [why] [Needs a report]

"Needs a report" puts it back on the board and it survives every rule - short
month, serving file, overlapping order, lifetime already delivered, all of it.
The row shows "kept on by hand" with your note on hover, so it never reads as
something the board asked for on its own.

All three are this cycle only. Next month the rules decide again, which is
what you want - the override is about this July, not about this client.


3. "JULY 2026" IN THE PERIOD BOX
---------------------------------
That is what made the first load say "0 clients across no month, 16,574 rows
read". It is a text field and it wanted 2026-07, so every row was filtered out
and the message read like the file was broken. "July 2026", "2026-7" and
"7/2026" all work now, and a period that matches nothing in the file refuses
the load and names the months the file actually holds instead of quietly
importing zero.

sample. That is the one number that says whether the serving file can be
trusted to take rows off the board, so it is now the actual count.
