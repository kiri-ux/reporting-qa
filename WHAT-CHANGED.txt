THE THING TO CHECK BEFORE DELETING THE OLD EXPORT
====================================================
It is not the columns. It is whether a file landed for EVERY partner.

The old export was one file for the whole board, so "did every partner come
through" was not a question anybody had to ask. One file per partner makes it
a real one, and a file that did not land is invisible: the partner has no
orders, no expected reports, and nothing anywhere saying so. It reads exactly
like a partner with nothing running.

So the orders page now names them. A red panel, the other way round from the
"not in the roster" one already there:

  N partners on the roster have no order lines loaded at all.

Open it, and if the list is only partners that genuinely have nothing running,
the old export has nothing left to give. If a live partner is on it, its file
did not land - and that is what would otherwise have gone unnoticed until
somebody asked where their reports went.
