A-1 APPLIANCE IS NOT MISSING
===============================
You are right that it makes no sense, and the answer is on the screenshot you
sent of it. The order's client is

  A-1 Appliance - Display

and the serving file calls the same client

  A-1 Appliance

The order tool puts the PRODUCT in the client name, because one client running
two products is two client records there. Keyed strictly those are two
different clients, so a client with thirty days of delivery and a live order
starting 10 February came back as having no order behind it - on a partner
whose file had landed perfectly well.

The match now tries the client name with a trailing product taken off, for the
products the order tool actually names: Display, Video, CTV, Social Mirror,
Social Mirror CTV, Meta, PPC, Performance Max, Native, Online Audio, YouTube,
TikTok, LinkedIn, DOOH, SEO, Live Chat, Mobile Conquesting, Amazon. Only a
trailing one, and only those words - "River Valley Builders/The Home Store"
stays exactly as it is.

AND THE PANEL SAYS WHICH OF TWO THINGS IT IS, on every row it still lists:

  no orders loaded for this partner at all
      the partner's export did not land

  this partner has orders, but not this client
      one client missing from a file that DID land - or a name the two tools
      spell differently, which is worth ruling out before anybody goes looking
      for a file that is already there

That column is the difference between a five-minute check and an afternoon.
Expect the list to be a good deal shorter, and what is left of it to say what
to do about itself.
