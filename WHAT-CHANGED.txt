THE SERVING FILE
=================
Orders page, under the import box: "Serving file". Upload, done.

Every rule about "did this run in July" has been an inference off two dates. A
line sold January to December and paused on the 2nd reads exactly like one
paused on the 30th. "IO Complete" is where every campaign that ever finished
comes to rest. Cancelled says a buy stopped and not which month. So the board
has been reading flight dates and guessing, and the guesses have been wrong in
both directions - reports asked for on campaigns that never ran, and campaigns
that ran with no row at all.

Delivery days settle it. 7+ days served, a report is owed. Fewer, the board
says it did not run, in those words.

WHAT IT NEEDS
  A client column, a business unit column, a date column. One row per client
  per business unit per day.

  The names are read off YOUR header, not fixed - client / advertiser /
  account, business unit / market / BU, date / day / serve date all work. The
  page prints back which columns it used, so a file that loads wrong says so
  instead of quietly counting the wrong column. If it cannot find one of the
  three it names which and prints your header.

  If there is an impressions, spend or clicks column, a day only counts when
  something delivered on it - a row of zeros is not a day. With no figures in
  the file at all, every row present counts, and the page says that is what it
  did.

WHAT IT CHANGES
  Loaded for a month, it replaces the date guess for that month entirely.
  Not loaded, nothing changes - the board reads dates exactly as before. A
  month with no file is not a month where nobody ran.

  A client in the order list that the file does not name reads as having served
  nothing. That is the point, and it is also what a client the two tools spell
  differently looks like - so the orders page counts them. A few is campaigns
  that went dark. Two hundred is a name matching problem, and you will see the
  number without going looking for it.

  The skip reason on the board says where the number came from: "served 2 days
  this month, per the serving file" is a fact, "ran 2 days this month" off the
  flight is a guess, and they should not read the same.
