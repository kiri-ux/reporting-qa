THE DAILY SERVE FILE READS ITSELF IN
=======================================
Anything named client-serve* in the same S3 folder as the orders is now read on
every sync. Punctuation is ignored, so client-serve, client_serve and
clientserve are the same thing - and the order import will not touch those
files, which matters because merged into the order list they would be 1.4
million rows of nothing recognisable.

I checked your column list against the parser and it reads without any changes:

  Business Unit  -> the partner
  Client         -> the client
  Date           -> the day        (NOT Campaign Start Date, which is also
                                    in the file - there is a test on that)
  Impressions    -> whether that day counted

A day counts when something actually delivered on it, so a row of zeros is not
a day. That is the same rule the uploaded file has always used.

ON ITS OWN TIMESTAMP. The serve file changes every morning and the order export
does not, so they are checked separately - otherwise noticing a new 2 MB serve
file would re-download several hundred megabytes of orders with it. And it can
never fail the order sync: a serve file that will not parse is logged and the
orders load anyway.

MERGED, NOT REPLACED, and this is the part that mattered. A file uploaded by
hand covers a whole month, so it replaces it. The daily one carries whatever
range it carries - if it replaced, a client on twenty days would read as
whatever this morning's file happened to mention, and drop off the board.

Merging counts alone is a choice between trusting the newest file and never
coming down, so the days themselves are kept now: one row per client per month
carries its list of dates, and a load is a union. Twenty days plus this
morning's two, one of which it had already seen, is twenty-one.

Rows already in the database have a count and no dates. That count is real, so
it is treated as a floor rather than replaced by something smaller.

Uploading by hand still replaces the month outright, which is what you want for
a corrected file. The Order list page says all of this above the upload box.
